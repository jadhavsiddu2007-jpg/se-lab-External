Kubernetes Commands

1. Basic Kubernetes Commands

Command Purpose
kubectl versionCheck Kubernetes version
kubectl cluster-infoDisplay cluster information
kubectl get nodesDisplay cluster nodes
kubectl get podsList pods
kubectl get pods -AList pods in all namespaces
kubectl get servicesList services
kubectl get deploymentsList deployments
kubectl get namespacesList namespaces

2. Pod Commands

A Pod is the smallest deployable unit in Kubernetes.

Command Purpose
kubectl get podsList pods
kubectl describe pod podnameDisplay pod details
kubectl logs podnameView pod logs
kubectl exec -it podname -- shEnter pod container
kubectl delete pod podnameDelete pod
kubectl run nginx --image=nginxCreate nginx pod
kubectl get pods -o wideShow pod details and IP

3. Deployment Commands

A Deployment manages multiple replicas of pods.

Command Purpose
kubectl create deployment nginx --image=nginxCreate deployment
kubectl get deploymentsList deployments
kubectl describe deployment nginxDisplay deployment details
kubectl scale deployment nginx --replicas=3Scale to 3 replicas
kubectl rollout status deployment/nginxCheck deployment status
kubectl rollout history deployment/nginxView rollout history
kubectl rollout undo deployment/nginxUndo latest rollout
kubectl delete deployment nginxDelete deployment

4. Service Commands

Services expose applications running inside pods.

Command Purpose
kubectl get svcList services
kubectl expose deployment nginx --port=80 --type=NodePortExpose deployment
kubectl describe svc nginxDisplay service details
kubectl delete svc nginxDelete service

5. Apply and Delete YAML Files

Command Purpose
kubectl apply -f file.yamlCreate/update resources
kubectl create -f file.yamlCreate resources
kubectl delete -f file.yamlDelete resources
kubectl get allList common resources
kubectl edit deployment nginxEdit deployment
kubectl get pods -wWatch pod changes

6. Minikube Commands

Minikube is used to run a local Kubernetes cluster.

Command Purpose
minikube startStart cluster
minikube stopStop cluster
minikube statusCheck status
minikube deleteDelete cluster
minikube dashboardOpen dashboard
minikube ipDisplay cluster IP
minikube service nginxOpen service
